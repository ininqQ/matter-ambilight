# Matter Ambilight

[English](README.md) · **Русский**

Свет в комнате меняется в цвет того, что на экране. Это как Philips Hue Sync, только для **любых цветных Matter-ламп** и прямо с компьютера на Windows: без моста, без Home Assistant и без облака.

- 🎬 **Лампы в цвет экрана.** Каждая лампа следит за своей частью экрана: слева, справа, по центру или за всем экраном. Цвет обновляется примерно 10 раз в секунду.
- 🖥️ **Свечение на втором мониторе.** Второй монитор показывает мягкое размытое продолжение края фильма, как ещё одна большая лампа.
- 🏠 **Лампы остаются в вашем умном доме.** Компьютер подключается к ним *вторым* Matter-контроллером (multi-admin). Apple «Дом», Google Home, Siri и остальное продолжают работать.
- ↩️ **Свет возвращается.** После остановки каждая лампа получает обратно цвет и яркость, которые были до запуска.
- ⚡ **Почти не нагружает процессор.** Экран захватывается через видеокарту с помощью ffmpeg, всего около половины одного ядра.
- 🇷🇺🇬🇧 Интерфейс на русском и английском, язык выбирается автоматически.

## Что нужно

- Windows 10/11.
- Цветные Matter-лампы с Wi-Fi. Лампы на Thread тоже должны работать, если компьютер достаёт до них по IPv6 через шлюз Thread.
- Лампы уже должны быть добавлены в какое-нибудь Matter-приложение: Apple «Дом», Google Home, Алису, SmartThings и т. п. Из него понадобится код сопряжения.
- [Node.js](https://nodejs.org) 20 или новее. Батник сам предложит его установить.
- Необязательно: ffmpeg, чтобы снизить нагрузку на процессор. Мастер настройки предложит его установить.
- Необязательно: второй монитор и Microsoft Edge или Google Chrome — для свечения.

## Быстрый старт

1. Скачайте последний релиз на странице [**Releases**](https://github.com/ininqQ/matter-ambilight/releases/latest) (**Source code (zip)**) и распакуйте в любую папку. Или сделайте `git clone`.
2. Дважды щёлкните **`Ambilight.bat`**. При первом запуске он сам поставит всё нужное и запустит мастер настройки.
3. В мастере введите код сопряжения для каждой лампы (как получить код — ниже), укажите, где стоит лампа и на каком мониторе вы смотрите фильмы.
4. Готово. Дальше просто запускайте **`Ambilight.bat`**. Чтобы остановить, нажмите **Ctrl+C** или закройте окно, и лампы вернутся к прежнему свету.

Чтобы потом добавить ещё лампы, запустите **`Add lamp.bat`**.

### Как получить код сопряжения

Лампа остаётся в своём приложении: вы только *делитесь* ею с компьютером.

| Приложение | Где найти |
|---|---|
| Apple «Дом» | лампа → настройки (прокрутить вниз) → **«Включить режим создания пары»** |
| Google Home | лампа → настройки → **«Связанные приложения и сервисы Matter»** → **«Связать»** |
| Другие | ищите в настройках лампы «поделиться с другими приложениями» или «режим сопряжения» |

Код состоит из 11 цифр (например, `1234-567-8901`) и действует около 15 минут. Для каждой лампы нужен свой код.

## Команды

Для обычного использования хватает `Ambilight.bat` и `Add lamp.bat`. Остальные команды запускаются в терминале из папки проекта:

| Команда | Что делает |
|---|---|
| `node ambilight.mjs start` | Синхронизация ламп и свечения. Если ламп ещё нет, сначала запускается настройка |
| `node ambilight.mjs setup` | Мастер настройки: добавить лампы, выбрать монитор |
| `node ambilight.mjs pair <код> [имя] [зона]` | Добавить лампу без вопросов |
| `node ambilight.mjs list` | Список ламп |
| `node ambilight.mjs test` | Зажечь каждую лампу своим цветом на 8 секунд, чтобы понять, какая где |
| `node ambilight.mjs preview` | Показать цвета зон в терминале, лампы не нужны |
| `node ambilight.mjs glow` | Только свечение на втором мониторе |
| `node ambilight.mjs unpair <id\|имя>` | Убрать лампу из этого компьютера. В других приложениях она останется |
| `node ambilight.mjs doctor` | Диагностика: мониторы, ffmpeg, браузер, сеть, лампы |

Пока синхронизация работает, она сразу перебивает любые изменения из приложения умного дома. Когда её остановите, лампы снова полностью ваши.

## Настройки — `config.json`

Файл создаёт мастер настройки, пример — [`config.example.json`](config.example.json). Изменения применяются при следующем запуске.

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `language` | `"auto"` | `"auto"`, `"en"` или `"ru"`. Ещё можно задать переменную окружения `AMBILIGHT_LANG` |
| `monitor` | `"primary"` | С какого монитора брать картинку: `"primary"`, номер (`0`, `1`) или часть имени |
| `fps` | 20 | Сколько раз в секунду анализировать экран |
| `maxUpdatesPerSecond` | 10 | Сколько раз в секунду можно обновлять одну лампу. На деле упирается в скорость лампы: обычные Wi-Fi-лампы успевают примерно 7–11 раз в секунду |
| `transition` | 0.1 | Плавность перехода в самой лампе, в секундах. Для спокойного режима — `0.4` |
| `smoothing` | 0.15 | Сглаживание: 0 — мгновенно, 0.8 — очень спокойно. Для спокойного режима — `0.35` |
| `saturationBoost` | 1.5 | Усиление цветов: цвета на экране обычно бледные |
| `minBrightness` / `maxBrightness` | 3 / 100 | Яркость ламп в процентах в тёмных и светлых сценах |
| `brightnessGamma` | 0.7 | Если меньше 1, сцены средней яркости становятся светлее |
| `networkInterface` | `null` | Сетевой интерфейс для поиска устройств, например `"Ethernet"`. `null` — все |
| `preferIpv4` | `true` | Подключаться сначала по IPv4 (см. «Если что-то не работает») |
| `capture` | `"auto"` | `"auto"` использует ffmpeg, если он есть. `"screenshots"` — запасной, более медленный способ |
| `ffmpegPath` / `ddaOutput` | — | Путь к ffmpeg и номер монитора для него, если они не определились сами |
| `lamps[].zone` | — | `left`, `right`, `center`, `all`, `top`, `bottom` или своя область: `{"x":0,"y":0,"w":0.2,"h":1}` (в долях экрана) |

### Свечение на втором мониторе — раздел `glow`

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `enabled` | `true` | `false` — выключить свечение |
| `monitor` | `"auto"` | Любой монитор, кроме того, с которого идёт захват, или часть имени монитора |
| `edge` | 0.3 | Какую долю ширины основного экрана у стыка отражать |
| `blur` | 45 | Размытие, px |
| `brightness` / `saturation` | 1.0 / 1.3 | Яркость и насыщенность свечения |
| `fade` | 0.85 | Насколько темнеет дальний край второго монитора: 0 — не темнеет, 1 — уходит в чёрный |
| `smoothing` | 0.3 | Плавность смены картинки |

Окно свечения открывается *позади* других окон, поэтому перед фильмом сверните окна на втором мониторе.

## Если что-то не работает

- **Лампа не находится при добавлении.** Снова включите режим сопряжения (у кода истекает срок) и сразу введите код. Компьютер и лампа должны быть в одной сети.
- **Подключение длится минуту и дольше, или лампы отваливаются.** VPN-клиенты на компьютере часто блокируют IPv6 в локальной сети. Оставьте `preferIpv4: true` (так по умолчанию). Сетевые интерфейсы показывает `node ambilight.mjs doctor`. Если поиск идёт не через тот интерфейс, укажите `networkInterface`, например `"Ethernet"`.
- **Лампы запаздывают или дёргаются.** Уменьшите `maxUpdatesPerSecond` и увеличьте `transition` или `smoothing`.
- **Онлайн-кинотеатры (Netflix и т. п.) дают чёрный экран.** Защищённое (DRM) видео захватить нельзя, это касается любых программ захвата экрана. Обычные плееры (VLC, mpv) и большинство сайтов работают нормально.
- **Сильная нагрузка на процессор.** Установите ffmpeg: `winget install Gyan.FFmpeg`. Нашёлся ли он, покажет команда `doctor`.
- **После Ctrl+C окно спрашивает «Завершить выполнение пакетного файла [Y/N]?».** Это стандартный вопрос Windows для батников, просто закройте окно.
- **Подробный лог:** выполните `set MATTER_LOG=info` и `set DEBUG=1`, потом запустите `node ambilight.mjs start`.

## Как это устроено

```
 экран ──ffmpeg ddagrab (видеокарта)──▶ кадр 192×80 ──▶ цвет каждой зоны ──▶ команды Matter ──▶ лампы
                                              │
                                              └──▶ отражённая полоса края ──SSE──▶ Edge во весь экран на мониторе 2 (размытие CSS)
```

- **Matter.** На компьютере работает контроллер [matter.js](https://github.com/project-chip/matter.js). Лампы добавляются стандартным способом multi-admin, поэтому они находятся сразу в двух «домах». Ключи доступа хранятся в `.matter-storage/`. Эта папка исключена из git, держите её при себе.
- **Скорость.** У каждой лампы не больше одной команды в пути, и она всегда получает самый свежий цвет, без очереди. Цвет и яркость отправляются, только когда действительно изменились.
- **Захват.** `ddagrab` из ffmpeg (Desktop Duplication API) берёт кадр прямо с видеокарты и уменьшает его. Без ffmpeg программа делает обычные снимки экрана в полном разрешении через [node-screenshots](https://github.com/nashaofu/node-screenshots).
- **Возврат света.** При запуске программа запоминает состояние ламп и возвращает его по Ctrl+C или при закрытии окна.

## Ограничения

- Только Windows: захват экрана и окно свечения используют функции Windows.
- Компьютер работает как Matter-контроллер с тестовым Vendor ID, как и другие самодельные контроллеры. Проверено на лампах Яндекс Лампочка E27 (Wi-Fi, Matter). Другие цветные Matter-лампы должны работать, но не проверялись.
- Защищённое (DRM) видео захватить нельзя.
